# Continuous improvement engine

Every completed conversation produces structured evidence. The engine merges recurring issues instead of creating duplicates.

Each improvement contains category, evidence summary, confidence, priority, actionable practice and lifecycle state. Recurrence increases confidence; later positive evidence reduces priority and can resolve an item. The UI always surfaces the most important current 3–5 items for the user's level and goals.

The level and improvement list are recalculated from accumulated evidence, not from a single conversation.
