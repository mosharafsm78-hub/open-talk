# Open Talk launch checklist

## Completed
- Responsive web UI
- PWA manifest
- Netlify configuration
- GitHub validation workflow
- Server-side profile-lock foundation
- Supabase schema foundation
- API health endpoint
- Production API contract
- AI assessment specification
- Realtime voice architecture
- Security baseline

## Required before public launch
- Supabase project and Auth configuration
- Apply database schema
- Configure Netlify secrets
- Connect production frontend to authenticated API
- Realtime matching
- WebRTC voice
- Consent and privacy controls
- Speech-to-text
- AI level assessment
- Persistent Need to Improve engine
- Conversation history and analytics
- Report/block/unmatch
- Moderation and appeals
- Rate limits and abuse prevention
- Monitoring, backups and recovery test
- Terms and privacy policy
- Android production build and Play testing

Do not label the product production-ready until these backend and security gates pass end-to-end.
