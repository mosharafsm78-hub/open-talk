# Open Talk QA matrix

## Critical journeys
- Signup/login/logout
- Profile save and server-enforced 30-day lock
- Match creation/cancel/retry
- Microphone permission denied/granted
- WebRTC connect, reconnect and end
- Consent before transcription
- AI level update after conversation
- Improvement item creation/merge/resolution
- Progress and achievement unlock
- Report/block/unmatch
- Moderator review and appeal
- Account deletion/data removal

## Adversarial tests
- Two users changing profile simultaneously
- Expired session
- Replay of API request
- Rate-limit exhaustion
- Malicious transcript input
- False/mass reporting
- Fake profile data
- Network loss during voice call
- Browser/mobile permission changes

Every critical journey must pass on desktop Chrome, Android Chrome and the Android app before Play Store production release.
