# Open Talk

Responsive frontend foundation for Open Talk: real conversation practice, AI assessment UI, continuous improvement, profile protection, progress, milestones and achievements.

## Deploy
Static site. Publish directory: /. No build command required.

## Production integrations still required
Supabase authentication/database, realtime matching, WebRTC audio, speech-to-text, AI assessment/feedback, moderation/reporting, notifications and abuse prevention should be connected before public launch. Browser localStorage and the demo level calculation are prototype-only.
